# 🧮 Dental CRM — Shared Domain & Algorithm Library (`@dental/shared`)

> **Ядро разделяемой бизнес-логики, контрактных Zod-схем, точной финансовой математики и медицинских алгоритмов DENTE Dental CRM.**  
> Используется параллельно в клиентском приложении (`apps/web`) и на сервере API (`apps/api`). Полная изоляция от DOM-зависимостей в чистых модулях (Pure TypeScript).

## 🏗️ Ключевые архитектурные инварианты

1. **Денежная математика строго в копейках (`money` & `finance`)**:
   - Все финансовые величины выражаются в **целочисленных копейках** (тип `bigint`).
   - Запрещено использование `number` с плавающей запятой (`0.1 + 0.2 !== 0.3`) для расчетов цен, скидок, налогов и зарплат.
   - Деление скидок по позициям чека выполняется по алгоритму распределения остатка (Largest Remainder Method), гарантируя схождение сумм копейка-в-копейку.
2. **Медицинская регуляторика и государственные стандарты**:
   - **ЕГИСЗ РЭМД CDA R3 XML (`cda`)**: генерация структурированных медицинских документов по стандартам Минздрава РФ с OID-идентификаторами и канонизацией XML (C14N).
   - **ФНС РФ Справка 13% НДФЛ (`documents/ndflXmlGenerator.ts`)**: генерация XML по форме КНД 1151156 с разделением на код 1 (стандартное лечение) и код 2 (дорогостоящее лечение).
   - **СанПиН 3.3686-21 (`sanpin` & `anesthesia/pkuDisposal.ts`)**: учет циклов стерилизации автоклавов класса B и 1-клик акты списания пустых карпул анестетиков.
3. **Безопасность пациента (Clinical Drug-Drug Interaction & DDI Safety)**:
   - Автоматическая проверка противопоказаний: НПВП + антикоагулянты (риск кровотечений), пенициллиновая аллергия, бронхиальная астма (сульфиты в анестетиках с адреналином), 3-й триместр беременности.
4. **Мандат 8n: Приоритет №1 — Соло-врач и небольшая клиника 1–3 кресла (Zero Dead-Ends)**:
   - До больших сетей нам ещё расти и расти! Все общие валидаторы и схемы Zod в первую очередь обслуживают 0-клик сценарии соло-практики: касса 54-ФЗ без обязательного ИНН физлиц, расписание без обязательного ассистента, мягкий овердрафт склада вместо блокировок, 1-клик списание анестетика пакетом. Сетевые схемы закладываются без тупиков (Zero Dead-Ends), не создавая преград для соло-врача.

## 📦 Модульная структура пакета (`packages/shared/src/`)

| Модуль | Файлы / Директория | Описание и ответственность |
| :--- | :--- | :--- |
| **`money`** | `src/money/` | Базовые типы денег, строгая арифметика копеек, безопасное форматирование в ₽ для UI. |
| **`finance`** | `src/finance/` | Калькулятор справки НДФЛ КНД 1151156, фиксация цен плана лечения (`priceLockEngine.ts`), валидация счетов. |
| **`cda`** | `src/cda/` | Спецификация CDA R3 XML: бланки 043/у, 043-1/у, 101, 104, 130, валидация по схемам Минздрава, C14N канонизация. |
| **`crypto`** | `src/crypto/` | Фасад КриптоПро ЭЦП (`cadespluginFacade.ts`), визуальный штамп открепленной подписи, SHA-256 хеширование. |
| **`imaging`** | `src/imaging/` | 16-битный DICOM-парсер, WebWorker для 3D Multi-Planar Reconstruction (MPR), Hounsfield Unit (HU) окна, HEIC декодер. |
| **`anesthesia`**| `src/anesthesia/` | Весовой калькулятор дозировки анестетика (артикаин, мепивакаин), контроль МДД, 1-клик списание ПКУ медсестрой. |
| **`clinical`** | `src/clinical/` | Движок DDI безопасности лекарств (`clinicalDdiDrugSafetyEngine.ts`), аудит качества карт начмедом (`cmoEmkQualityAuditEngine.ts`). |
| **`curator`** | `src/curator/` | Движок куратора пациентов (`curatorEngine.ts`), сквозная воронка конверсии планов лечения. |
| **`doctor`** | `src/doctor/` | Кокпит смены врача (`doctorShiftCockpitEngine.ts`), расчет выработки и сдельного % Net Revenue. |
| **`sanpin`** | `src/sanpin/` | Журналы СанПиН 3.3686-21, тесты азопирама и фенолфталеина, контроль индикаторов автоклава B. |
| **`schedule`** | `src/schedule/` | Экспорт расписания в iCalendar (RFC 5545) для Яндекс Календаря и Apple/Google Calendar. |
| **`security`** | `src/security/` | Валидаторы надежности паролей персонала, проверка валидности СНИЛС и ИНН по контрольным суммам. |
| **`types`** | `src/types/` | Центральные интерфейсы монорепозитория: зубная формула FDI, визиты, пациенты, роли RBAC. |

## 🧪 Сборка и тестирование

```bash
# Сборка пакета (компиляция TypeScript в dist/)
npm run build -w @dental/shared

# Проверка типов (TypeScript strict mode)
npm run typecheck -w @dental/shared

# Запуск юнит-тестов (Node.js test runner)
npm test -w @dental/shared
```
