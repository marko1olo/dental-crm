## ⚠️ СКОЛЬЗКИЕ МЕСТА И ИНЖЕНЕРНЫЕ ЛОВУШКИ (ЧИНИТЬ ПРИ ВСТРЕЧЕ)
- **Неслойный CSS vs Tailwind:** неслойные утилиты (`.flex-1` вне `@layer`) перебивают `@layer utilities` (`sm:flex-none`, `md:hidden`) и незаметно режут кнопки — кастомные примитивы держать в `@layer`; одна кнопка `[X]` в DOM через CSS `order`; шкала `z-index` без `z-[10000]` (Sticky `20`, TopBar `30`, Portal `40`, Sheet `50`, Studio `100`, Toast `200`).
- **Пост-правка после скриншота = брак:** любая правка CSS/JSX *после* съёмки обнуляет PNG-пруф; каждый итоговый снимок проверять на правый клиппинг текста, наложение бейджей/чипов и честность A4-печати (`.print-paper-sheet[data-preserve-white="true"]` и `@media print` без `bg-white` в экранных модалках; бланки поддерживают пустые поля `____`).
- **Анти-автоподбор и ложный успех UI:** бан `.limit(1)` фолбэков на случайного пациента/услугу/врача (только селектор/`404`/Empty State); не закрывать модалку и не ставить оптим. статус («доставлен ОФД») при `4xx`/`5xx`; автосейв срабатывает строго по `isDirty` (0 мутаций на монтировании); таблицы `>100` строк виртуализировать (`<=35` DOM-строк).
- **Транзакции PG18, блокировки и сайд-эффекты:** блокировать строки в детерминированном порядке `ORDER BY id ASC FOR UPDATE` (0 `40P01` дедлоков); массовые апдейты через `UPDATE ... FROM (VALUES ...)`; WebSocket/LAN/ККТ/SMS-эффекты пускать строго ПОСЛЕ `COMMIT` (`onTenantTxCommit`), никогда внутри незакоммиченной TX; `idempotency_keys` (с проверкой payload hash) писать в той же TX, что и бизнес-таблицы; keyset SQL (`(updated_at, id)` + `LIMIT`) вместо `SELECT *` без пагинации.
- **BigInt JSON, Таймзоны, Утечки & Git-гонки:** явно сериализовать `bigint` до `reply.send()` (`Do not know how to serialize a BigInt`); даты/слоты форматировать в `clinicTimezone` клиники, без UTC-сдвига `toISOString().slice(0, 10)`; чистить `URL.revokeObjectURL`, observers/SSE/таймеры при unmount и гасить временные тестовые серверы после съёмки PNG (снимать на непустых данных!); перед `git commit` проверять `git diff --cached --name-only` против чужих файлов (или `git commit --only`), не трогая `.git/index.lock` живых воркеров.
