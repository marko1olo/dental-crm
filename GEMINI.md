## ⚠️ СКОЛЬЗКИЕ МЕСТА И ИНЖЕНЕРНЫЕ ЛОВУШКИ (ЧИНИТЬ ПРИ ВСТРЕЧЕ)
- **Неслойный CSS vs Tailwind:** неслойные утилиты (`.flex-1` вне `@layer`) перебивают `@layer utilities` (`sm:flex-none`, `md:hidden`) и незаметно режут кнопки — кастомные примитивы держать в `@layer`; одна кнопка `[X]` в DOM через CSS `order`; шкала `z-index` без `z-[10000]` (Sticky `20`, TopBar `30`, Portal `40`, Sheet `50`, Studio `100`, Toast `200`).

- **Анти-автоподбор и ложный успех UI:** бан `.limit(1)` фолбэков на случайного пациента/услугу/врача (только селектор/Empty State); не закрывать модалку, не очищать черновик и не ставить успех при `4xx`/`5xx`, `fetch().catch(() => null)` или `crypto.randomUUID()` на битом JSON; парсить `res.json()` через `unwrapEnvelope` + Zod/guard; автосейв строго по `isDirty`; списки `>100` строк виртуализировать (`<=35` DOM).
