## 🚨 ГЛАВНЫЕ ПРАВИЛА

Канонический источник — `.agents/AGENTS.md` и `.agents/THE_HAMMER_MASTER_PROMPT.md`.

1. **Читай код и документацию перед правками**: Всегда полностью считывай целевой файл перед изменениями. Дописывать быстрый патч в конец непрочитанного файла — критическое нарушение.

3. **Никаких хардкодов**: Использовать переменные окружения, типы Zod и интерфейсы TypeScript. Ни портов, ни эндпоинтов, ни учётных данных, ни магических строк в коде.
4. **Раздельные коммиты, неприкосновенность чужих правок и обязательный пуш (Мандат 8an)**: 
   - `git add` СТРОГО атомарно и поименно по конкретным файлам задачи (`git add <file>`). Рядом параллельно работают другие субагенты, оркестратор и разработчик! Слепой `git add .` или `git add -A` КАТЕГОРИЧЕСКИ ЗАПРЕЩЕН.
   - Строжайший запрет деструктивных команд (`git reset --hard`, `git restore .`, `git checkout -- .`, `git clean -fd`). Запрещено затирать чужие файлы и откатывать чужой труд.
   - Подробнейшее оформление коммитов по Conventional Commits (Why, What, Proof, Docs Sync) — никаких куцых отписок!
   - Завершил задачу — ОБЯЗАН закоммитить и запушить в оба ремоута (`origin` и `gitlab`).
5. **Запрет мождибаке (UTF-8)**: Не использовать PowerShell here-strings и `node -e` для ЗАПИСИ кириллицы. Для read-only проверок `node -e` допустим.
