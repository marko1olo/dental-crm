### 1.4 Тупик сохранения реквизитов (ДОСТИЖИМ по коду, живьём НЕ наблюдался)

Опаснее, чем просто отсутствие полей. Валидатор блокирует сохранение по полям, которых
нет на экране.

`AppHelpers.tsx:4876-4889`, `patientAdministrativeProfileDraftIssue`:
```
if (draft.preferredAppointmentStart && !draft.preferredAppointmentEnd) {
  return "Укажите конец удобного времени приема или очистите начало.";
}
```
Дальше: `PatientsView.tsx:126-130` — при непустом сообщении
`patientAdministrativeProfileReadyToSave` становится `false`, кнопка «Сохранить реквизиты»
(`:657`) отключается, показывается красное сообщение (`:522-524`), плашка встаёт в
«Ошибка» (`:510`).

Полей `preferredAppointmentStart` и `preferredAppointmentEnd` на экране нет ни одного.
Администратор видит требование «укажите конец удобного времени приема», не может ни указать
конец, ни очистить начало, и **теряет возможность сохранить паспорт, ИНН, СНИЛС и
представителя** для этого пациента навсегда. Через интерфейс выхода нет.

Состояние «начало есть, конца нет» создаёт сам сервер.
`apps/api/src/sampleData.ts:10421-10427`:
```
const preferredAppointmentEnd =
  preferredAppointmentStart &&
  requestedPreferredAppointmentEnd &&
  clockToMinutes(requestedPreferredAppointmentEnd) > clockToMinutes(preferredAppointmentStart)
    ? requestedPreferredAppointmentEnd
    : null;
```
Начало сохраняется, конец обнуляется, если он отсутствует, невалиден или **равен началу**.
Полупара сохраняется. И эта нормализация прогоняется по **всем** пациентам при загрузке
состояния: `sampleData.ts:5054` `applyPersistentState` → `:5065`
`normalizePatientAdministrativeProfiles()` → `:10462-10467` цикл по `patients`.

Дополнительно: колонка `administrative_profile` — `jsonb`, `$type<>` в Drizzle это только
compile-time, на чтении рантайм-валидации нет. Полупара из импорта, сида или прямого SQL
дойдёт до клиента без сопротивления.

Ограничение достижимости, честно: PUT из веб-приложения полупару не создаст, её отбивает
`updatePatientAdministrativeProfileSchema` (`shared:4276-4295`). Пути входа — сид, импорт,
прямой SQL, строки, записанные до появления `superRefine`, и нормализатор при загрузке.
