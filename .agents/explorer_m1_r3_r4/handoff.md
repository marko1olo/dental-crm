## 2. Logic Chain

1. **Premise 1 (Observation 1 & 4)**: `scripts/ops-panels-shots.mjs` injects `dente_staff_token` into `localStorage` via CDP evaluation (`applySessionTokens`). However, automated execution of CDP screenshot tasks does not dispatch physical DOM mouse/keyboard events.
2. **Premise 2 (Observation 1)**: Because no physical DOM events (`mousemove`, `keydown`, `pointerdown`) occur during long-running automated script executions, `App.tsx`'s 5-minute inactivity timer expires.
3. **Premise 3 (Observation 1 & 2)**: Expiration of the inactivity timer executes `safeLocalStorageRemoveItem("dente_staff_token")` and sets `showStaffPinPad = true`. `App.tsx` immediately unmounts the workspace shell and renders `<StaffPinPad />` (the shift lock screen).
4. **Premise 4 (Observation 3)**: When `ops-panels-shots.mjs` attempts to capture a workspace panel while `<StaffPinPad />` is on screen, `assertSectionOnScreen` fails to locate the panel marker.
5. **Conclusion (Observation 3 & 4)**: `ops-panels-shots.mjs` catches the missing marker, sets `wrongSection = true`, renames the output file to `..._ПУСТО.png`, and writes a diagnostic miss image instead of a valid visual proof plate.
6. **Quality Gates Premise (Observation 5)**: Monorepo encoding and TypeScript compilation standards are fully satisfied across `@dental/shared`, `@dental/api`, and `@dental/web`.
