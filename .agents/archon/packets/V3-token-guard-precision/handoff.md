## Что изменено

1. **scripts/check-css-tokens.mjs** — `CSS_DECLARATION = /(?:^|[{;}])\s*(--[\w-]+)\s*:/g`.
   Объявление считается только там, где оно может стоять по синтаксису: после `{`, после `;`,
   после `}` вложенного правила или в начале файла. `}` включён осознанно — вложенные правила
   в CSS законны, а имя класса от него не пострадает: перед `--` в `.foo--bar` стоит буква.
   Флаг `m` не нужен: перевод строки уже покрыт `\s*`, а селектор, начинающийся с `--`, в CSS
   невозможен. Проверено, что все три варианта привязки (`[{;]`, `[{;}]`, `[{;}]`+`m`) дают на
   рабочем дереве одинаковые 147 имён — то есть выбор не влияет на результат, а `}` берётся
   как более верный.
2. **scripts/check-css-tokens.mjs** — имена из JS берутся из дерева TypeScript
