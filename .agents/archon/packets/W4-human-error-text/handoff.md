  !isAdding && !isLoading` → «Рекламации и осложнения отсутствуют». Это журнал осложнений

  отказе `reasons` пуст → `false` → карточка утверждает «пациент не заблокирован» и
  подписывает кнопку «Добавить в черный список». Комментарий на `:139-141` закрывал этот
  же риск для состояния «грузится»; состояние «не удалось» проходило мимо него. По такому
  экрану администратор запишет на приём того, кому запись запрещена во всех клиниках сети.
