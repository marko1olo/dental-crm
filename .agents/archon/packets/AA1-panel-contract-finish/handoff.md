Про §3 «что делать, если кнопки нет» — ПРОВЕРЕНО отдельным тестом: у 404, 400 и 422 текст отказа
заканчивается словами «сообщите администратору», у 413 — «уменьшите объём». То есть шаг без кнопки
есть в каждом случае, где кнопку убрали. Тупика нет.

Тест `lib/panelStateText.test.ts`: снятое поле больше не проверяется, проверяется новое поведение
(7 новых тестов, 24 всего):
- ни при загрузке, ни при пустоте кнопки нет; при отсутствии ответа подпись «Повторить»;
- 400/404/413/422 не дают подписи вовсе;
- 401/403 дают подпись, упоминающую вход (regex `/вош|вход/i`);
- если подписи нет, заголовок отказа обязан называть шаг, которому кнопка не нужна;
- подпись кнопки без латиницы, без цифр и с большой буквы;
- `panelStateText` не дописывает к `notLoadedTitle` НИ ОДНОГО своего слова (сверка с точной
  склейкой по всем 15 кодам + null);
- панель с названием в единственном числе никогда не получает «не загружены»;
- два теста читают исходники ВСЕХ панелей проекта с диска: у каждой есть `notLoadedTitle`, ни у
  одной не осталось `title`, и ни одна не положила в `notLoadedTitle` просто название вместо
  предложения об отказе. Механический перенос названия компилируется молча — поймать его может
