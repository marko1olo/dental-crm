[ARCHON] fix(диктовка): продиктованный текст приема исчезал при перезапуске сервера

Расшифровки диктовки жили только в модульном массиве apps/api/src/speech/storage.ts
и нигде больше. tsx watch перезапускает процесс на каждое сохранение файла, деплой
перезапускает его штатно — и продиктованный врачом текст приема пропадал без ошибки,
без предупреждения и без следа. Это медицинская документация.

Вытеснение из кэша добивало остальное: срез по 80 записям и 600 фрагментам резал
массив, ни разу не проверив, сохранён ли текст хоть где-нибудь.

Что сделано:
- Каждая принятая запись пишется в существующую таблицу ai_jobs со значением
  kind = voice_transcription, которое уже было в перечислении ai_job_kind. Новых
  таблиц не заводится, db/schema.ts не тронут. Одна строка на запись диктовки:
  result_text — собранный текст (читается обычным SQL), input_text — JSON-конверт
  с полными фрагментами для точного восстановления, input_storage_path — ключ
  speech-recording://<recordingId> для повторной записи поверх.
- Кэш восстанавливается из PostgreSQL при старте модуля, каждый фрагмент проверяется
  схемой speechTranscriptionChunkSchema.
- Вытеснять разрешено только фрагменты, подтверждённо лежащие в базе. Всё остальное
  остаётся в памяти, даже если лимит превышен.
- Организация берётся из visits.organization_id или patients.organization_id. Раньше
  бралась первая попавшаяся строка organizations, а при пустой таблице — случайный
  UUID. В базе две организации, то есть текст одной клиники мог быть записан на другую.
  Если ни пациента, ни приема нет, фрагмент отклоняется с кодом 400, а не приписывается
  выдуманному арендатору.
- Неудачная запись в базу не глотается: она уходит в лог и отдельным предупреждением
  на сам фрагмент, откуда попадает в предупреждения сборки записи и видна врачу.
- Запись по одной recordingId сериализована цепочкой промисов; элемент карты удаляется,
  как только цепочка опустела. Таймеров и подписок не добавлено.

Горячий кэш сохранён как был: живая лента диктовки в UI работает через него,
долговременность добавлена под ним, а не вместо него.
