[ARCHON] fix(егисз): журнал обмена с государственной системой виден всем клиникам и не объявлен в drizzle

Таблица egisz_logs существует в базе с миграции 0000 (строки 521-529) и не имеет
колонки organization_id: запрос по ней падает с «column "organization_id" does
not exist» — проверено живым запросом к базе. Это журнал передачи медицинских
данных в ЕГИСЗ: каждая строка называет пациента и приём, а error_details хранит
ответ государственной системы с подробностями отказа. Пока принадлежности
клинике нет, выборка «что мы отправили» возвращает строки всех клиник сразу, и
отфильтровать их нечем.

Второй дефект — причина, по которой первый прожил незамеченным: в
apps/api/src/db/schema.ts таблица не была объявлена вообще (rg -c 'egiszLogs' по
файлу давал 0), а переписи схемы этого проекта ходят по объявлениям drizzle.
Таблица есть в базе, ORM о ней не знает, поэтому ни одна проверка изоляции
арендаторов её не осматривала.

Колонки объявлены по факту DDL, а не по догадке: сверено с information_schema
живой базы — те же семь колонок и те же внешние ключи patient_id → patients(id)
и visit_id → visits(id), оба ON DELETE cascade.

Существующие строки: select count(*) from egisz_logs дал 0, поэтому NOT NULL
применяется без переноса данных. Порядок «дозаполнить, затем NOT NULL» в
миграции 0145 всё равно соблюдён, как в 0119: файл должен примениться и на
установке, где журнал не пуст. Источник владельца — patient_id: он NOT NULL, у
него внешний ключ на patients, а patients.organization_id объявлен NOT NULL
(тоже проверено по information_schema), то есть владелец восстанавливается
однозначно. DEFAULT не ставится намеренно: клиника по умолчанию приписала бы
одной клинике отчётность другой и сделала бы ошибку невидимой.

Статус объявлен как text, хотя в базе это egisz_status_enum: pgEnum в schema.ts
обязан иметь одноимённый контракт <имя>Schema в @dental/shared, иначе перепись
перечислений tests/enumContractDrift.test.ts краснеет, а контракта для статуса
ЕГИСЗ нет вовсе. Причина записана рядом с колонкой. Приведение text-параметра к
перечислению проверено запросом к живой базе.

Миграция НЕ применена: база и миграции — общий гейт ведущего.
