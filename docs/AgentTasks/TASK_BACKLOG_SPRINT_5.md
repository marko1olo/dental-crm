## ТАСКИ СПРИНТА 5

### 📌 TASK-5.1: Миграция индексов внешних ключей (28 FKs)
- **Файлы:** `apps/api/drizzle/0173_missing_fk_indexes.sql`, `apps/api/src/db/schema/`
- **Проблема:** PostgreSQL не индексирует Foreign Keys автоматически. Полнотабличные `Seq Scan` при `CASCADE` удалениях и `JOIN` операциях в клинике, бухгалтерии и бонусах.
- **Решение:** Создать `CREATE INDEX IF NOT EXISTS` для 28 внешних ключей и синхронизировать с `schema/clinical.ts`, `schema/billing.ts`, `schema/inventory.ts`, `schema/patients.ts`.

### 📌 TASK-5.2: Защита от гонок конверсии лидов (CRM Lead Lock)
- **Файл:** `apps/api/src/routes/leads.ts`
- **Проблема:** Метод `/api/leads/:id/convert` читает лид без блокировки. При одновременном клике двух администраторов создаются 2 дубликата пациента и 2 слота в расписании.
- **Решение:** Обернуть в `db.transaction(async (tx) => { ... })` с пессимистической блокировкой `crmLeads` через `.for("update")`.

### 📌 TASK-5.3: Валидация матрицы лекарств 1094н по реальным данным пациента
- **Файл:** `apps/api/src/routes/pharmacology.ts`
- **Проблема:** Строки 179–182 жестко захардкодили возраст 35 лет, отсутствие беременности и лактации. Матрица межлекарственных взаимодействий (Приказ Минздрава 1094н) выдавала расчет для вымышленного пациента.
- **Решение:** Вычислять точный возраст в годах из `patient.birthDate`, учитывать пол и статус беременности из ЭМК.

### 📌 TASK-5.4: Декомпозиция форм `DocumentsView.tsx`
- **Файлы:** `apps/web/src/components/documents/forms/PatientIntakeQuestionnaireForm.tsx`, `apps/web/src/components/documents/forms/TreatmentPlanDocumentForm.tsx`
- **Проблема:** Формы анкеты пациента и плана лечения загромождают `DocumentsView.tsx` (7k+ строк).
- **Решение:** Вынести в модульные компоненты с чистыми типизированными пропсами.
