## 1. Канонический ключ и название
- **feature_key**: `кадры::справедливое_распределение_конверсии_повторной_записи`
- **Наименование**: Порог 15 минут для зачисления конверсии записи Врачу vs Админу
- **Конкуренты-аналоги**: IDENT
- **Продуктовый модуль**: Аналитика / Кадры

---

## 2. Пользовательская проблема (User Problem)
Отсутствие автоматизации фичи "Порог 15 минут для зачисления конверсии записи Врачу vs Админу" в клинике приводит к ручным рутинным операциям, задержкам обслуживания пациентов и риску человеческой ошибки.

---

## 3. Кому приносит пользу (Who Benefits)
Администратор клиники, Врач-стоматолог, Руководитель, Главный врач.

---

## 4. Подробный пользовательский сценарий (User Flow & Behavioral Scenario)
1. Пользователь открывает модуль "Аналитика / Кадры".
2. Система производит считывание текущего состояния и данных.
3. Выполняется целевое действие с отображением статуса в UI.
4. Данные синхронизируются с базой данных PostgreSQL.

---

## 5. Детали интерфейса (UI Details & Layout)
• Модальный компонент в представлении модуля Аналитика / Кадры.
• Кнопки управления целевым действием.
• Индикаторы статусов и апертуры предупреждений.

## 9. Состояние у нас в Dental CRM (Our Status & Code Evidence)
- **Текущий статус**: [НЕТ] / [DEBT]
- **Доказательство в кодовой базе**: В кодовой базе реализован сквозной расчет конверсий воронки и выручки сотрудников (`apps/api/src/routes/analytics.ts`, `apps/web/src/components/analytics/ExecutiveFunnelMetrics.tsx`). Специфическое кадровое правило справедливого разделения конверсии повторной записи по 15-минутному окну ($\Delta t = \text{created\_at} - \text{completed\_at} \le 15$ мин -> Врач, $\Delta t > 15$ мин -> Администратор) находится в бэклоге `[DEBT]`.
- **Задействованные модули для будущей реализации**:
  - Frontend: `apps/web/src/components/staff/RebookingConversionSettingsModal.tsx`, расширение фильтров в `StaffKpiReportModal.tsx`
  - Backend: `apps/api/src/routes/analytics.ts` (`GET /api/analytics/rebooking-conversion`), `apps/api/src/routes/staff.ts`
  - Schema: `apps/api/src/db/schema/rebookingAttributionSettings.ts` (`rebooking_attribution_settings`)
  - Shared: `packages/shared/src/staff/rebookingAttributionSchema.ts`
