> **Статус:** Внедрено и верифицировано Red Team Inquisitor  
> **Мандаты:** Мандат 8b (декомпозиция <= 110 строк), Мандат 8e (автономия врача и запрет блокировок), Мандат 8n (соло-врач и небольшая клиника), Мандаты 8x и 8ap (чистый клинический язык без советского канцелярита и номеров приказов), Мандат 8am (единый дизайн-код: 1 Primary CTA), Apple HIG (сенсорные зоны >= 44px, Natural Thumb Zone).

## 1. Архитектурный обзор и декомпозиция (Мандат 8b)

В рамках ликвидации монолита `visit-diary-043.css` (1 088 строк) создана модульная архитектура стилей в `apps/web/src/components/visit/diaryStyles/`:
Каждый файл строго удовлетворяет ограничению $\le 110$ строк:

| Файл | Назначение | Строк |
| :--- | :--- | :--- |
| `clinicalDiaryTokens.css` | Токены темы, переменные поверхностей, подложка `.clinical-diary` и темная тема | 62 |
| `clinicalDiaryHeader.css` | Шапка дневника, бейджи статуса, 1 Primary CTA изумрудная кнопка | 99 |
| `clinicalDiarySoapFields.css` | Сетка SOAP, секции S, O, A, P, адаптивные поля ввода | 96 |
| `clinicalDiaryPresets.css` | Быстрые протоколы СтАР, индикатор дебаунсированного автосейва | 92 |
| `clinicalDiarySomaticNorm.css` | 1-клик кнопка «✓ Соматически здоров / Норма» | 81 |
| `clinicalDiaryIcd10Selector.css` | Клинический селектор диагнозов МКБ-10, чипы и выпадающий список | 102 |

Старый монолитный файл `apps/web/src/styles/visit-diary-043.css` заменен на сверхтонкий фасад (7 строк), перенаправляющий вызовы в модульную структуру.

## 2. Клиническая автономия врача (Мандат 8e)

1. **Норма в 1 клик:**
   Кнопка «✓ Соматически здоров / Интактно» на панели дневника моментально проставляет статус нормы без утомительного заполнения десятков пустых полей.
2. **Debounced Autosave (300 мс):**
   Каждый символ сохраняется в локальное состояние с дебаунсом 300 мс, гарантируя абсолютную сохранность клинических записей при смене вкладок или случайном закрытии модального окна.
3. **Запрет блокировок кнопок:**
   Кнопки «Сохранить черновик», «Печать карты», «Завершить приём и счёт» никогда не блокируются (`disabled = false`) из-за незаполненных второстепенных полей.

## 3. Ликвидация бюрократического канцелярита (Мандаты 8x и 8ap)

1. Все упоминания и селекторы советского приказа `043/у` выжжены из пользовательского интерфейса.
2. Используется понятный живой клинический русский язык:
   - Вместо «Форма 043/у» $\to$ «Медицинская карта приёма» / «Дневник приёма».
   - Вместо бюрократических кодов $\to$ структурированные клинические записи SOAP и чипы СтАР.
