# Архитектура электронных листков нетрудоспособности и справок (ЭЛН)

## 1. Контекст и ликвидация потемкинских деревень (Мандаты 8wy, 8zu, 8f)
Ранее в модуле больничных листов (`apps/web/src/components/documents/sickLeave/`) присутствовали бутафорские компоненты («потемкинские деревни»):
- `ElnDigitalSignatureSection.tsx` — фейковый симулятор КриптоПро с таймерами и невалидными сертификатами;
- `ElnVkProtocolSection.tsx` — бутафорский протокол 4-членной врачебной комиссии (ВК) для соло-врача на 1-2 кресла;
- `ElnSfrPayloadSection.tsx` — дев-песочница с прямым отображением сырого XML для СФР.

В рамках рефакторинга все бутафорские симуляторы полностью ликвидированы:
1. Удалены файлы симуляций КриптоПро, ВК и песочницы СФР.
2. Генератор `elnXmlGenerator.ts` очищен от фейковых сертификатов и сохранен как чистый экспорт структурированных данных.
3. Вся логика переведена на реальную клиническую автономию: экспорт в медицинскую карту приёма (дневник SOAP), печать стандартизированной памятки пациенту (А5) и ведение реестра выданных листков нетрудоспособности.

## 4. Клиническая автономия врача (Мандаты 8e, 8n)
- Кнопки («В карту», «Печать», «Выдать справку») **НИКОГДА** не блокируются (`disabled`).
- Быстрый выбор продолжительности освобождения в 1 клик: пилюли `3 дн.`, `5 дн.`, `10 дн.`, `14 дн.`.
- Автоподтягивание диагноза и данных пациента из текущего визита.
- Свобода действий врача: автоматический расчет дней при смене дат без зацикливаний и модальных ловушек.
