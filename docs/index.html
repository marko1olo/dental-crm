Windows Inno Setup & PowerShell Tray
.\installer\windows\Setup-DenteLanNetwork.ps1 -StaticIp 192.168.1.100
1. Запустите DenteSetup.exe (автоматический установщик службы Windows). 2. Служба DenteService регистрируется с автоматическим перезапуском при сбое. 3. Трей-компаньон DenteTray.ps1 показывает статус базы данных и локальный IP. 4. Открытие портов брандмауэра для подключения планшетов iPad / Android.
