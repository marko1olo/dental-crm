3. **Мандат 8am (Единый дизайн-код):** Ровно 1 Primary CTA кнопка («Внести в карту») изумрудного цвета на видимый экран.
4. **Мандат 8wx (Лимиты файлов):** Все компоненты и CSS строго $\le 120$ строк, 0 неразрешенных CSS-токенов (`node scripts/check-css-tokens.mjs`).
