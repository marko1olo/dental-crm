1. **Мандат 8e (Автономия врача):** Кнопки («Сохранить», «Завершить приём», «Печать», «Оплатить») никогда не блокируются (`disabled`). Физиологическая норма в 1 клик («✓ Соматически здоров / Интактные зубы»). Дебаунсированный автосейв черновиков на лету. Свобода скидок врача до 100%.

4. **Мандат 8x & 8ap (Statutory Purge):** Полное искоренение устаревших номеров приказов и советского канцелярита в UI («Медицинская карта приёма» вместо «043/у», «Прейскурант услуг» вместо «804н», «Кассовый чек» вместо «ФФД 1.2»). Тотальный запрет упоминаний брендов конкурентов.
