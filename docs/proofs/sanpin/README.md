## 2. Архитектурные инварианты (Мандаты 8e, 8n, 8ap, 8aq, <= 120 строк)
- **Искоренение советских номеров приказов (Мандат 8ap):** Полная очистка кода, хуков, компонентов и интерфейса от «Форма 257/у» и «Форма 366/у» в пользу чистой доменной номенклатуры: «Журнал контроля автоклавирования» / «Журнал работы стерилизаторов» и «Журнал предстерилизационной очистки и азопирамовых проб». Сохранены фасады обратной совместимости (<= 80 строк) для внешних потребителей.
