## 1. Архитектура и Sweet Spot компонентов

1. **`SanpinSterilizationHubModal.tsx`** (443 строки — канонический Sweet Spot 350–450 строк):
   - Единый мастер-хаб с 4 вкладками:
     1. **Экспресс-смена**: выбор программы (134°C Класс B / 121°C Класс B), пресет упаковок (6, 12, 18, 24 шт.), ответственный сотрудник, блок контроля качества (Норма СанПиН: Индикатор 5 кл., Азопирам, Фенолфталеин), превью фонового списания со склада (Soft Negative Stock).
     2. **Журнал автоклавирования**: реестр циклов (время, цикл, автоклав, параметры 134°C / 2.1 бар / 5 мин, статус Стерильно, ответственный).
     3. **Очистка и пробы**: контроль качества предстерилизационной очистки (партия изделий, выборка >= 1% от 3 шт., азопирам и фенолфталеин отрицательные, вердикт: Годно).
     4. **Печать журналов (А4)**: интерактивная таблица и кнопка печати бланка А4 для инспекций Роспотребнадзора.
   - Ровно **ОДНА Primary CTA кнопка** `#0d9488` (`var(--teal)`): «Зафиксировать цикл автоклавирования».

2. **`sanpinCatalogData.ts`** (245 строк — строгий Sweet Spot 200–250 строк):
   - SSOT программ стерилизации (134°C универсальная, 121°C деликатная, 134°C экспресс).
   - Стандарты очистки ПСО (100% норма: азопирам отрицательный, фенолфталеин отрицательный).
   - Расчет фонового списания со склада: крафт-пакеты, химические индикаторы 5 класса, азопирам, фенолфталеин (`calculateBatchStockDeduction`).
   - Функция формирования батча смены в 1 клик (`createOneClickShiftBatch`).
   - Генератор чистого печатного HTML бланка А4 (`generateSanpinPrintHtml`).

3. **`DirectSanpinLauncher.tsx`** (80 строк — строгий Sweet Spot 50–90 строк):
   - Реагирует на URL хэши `#sanpin`, `#autoclave`, `#sterilization`, URL параметры `?sanpin=1`, `?sterilization=1`, `?autoclave=1`.
   - Реагирует на события `dente:open-sanpin` и `dente:open-autoclave`.
   - Монтирован в `AppShell.tsx` (строка 174).
