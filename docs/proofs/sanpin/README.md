# SanPiN 3.3686-21 & Batch Sterilization Visual Proofs

Этот каталог содержит доказательства инструментального аудита Red Team для домена автоклавирования, предстерилизационной очистки и санитарно-эпидемиологических журналов клиники DENTE (СанПиН 2.1.3678-20, СанПиН 3.3686-21, МКБ, требования Роспотребнадзора).

## 1. Канонические скриншоты (4-State Visual Proof + Modals)

1. **PC Light (1440×900)**: `pc_light_sanpin_sterilization_1440x900.png`
   - Полный журнал автоклавирования и стерилизации.
   - 1-клик быстрый запуск цикла смены: «Запустить цикл автоклавирования (134°C, 2.1 бар, 5 мин)» (`.primary-button`).
   - Вторичные действия: «Щадящий цикл (121°C, 20 мин)», «Очистка (азопирам): норма», «Партия лотков к приёму», «Экспорт журнала для проверки».
   - Ликвидация поштучного сканера крафт-пакетов из фильтров тулбара.
   - Фиксация переходов термохимических индикаторов 4–5 классов (Бежевый -> Темно-коричневый).

2. **PC Dark (1440×900)**: `pc_dark_sanpin_sterilization_1440x900.png`
   - Тёмная клиническая тема без паразитного свечения и визуальных артефактов.
   - Контрастные статусные плашки, чёткие границы строк и чипы параметров цикла.

3. **Mobile Light (390×844)**: `mobile_light_sanpin_sterilization_390x844.png`
   - Адаптация под Apple iOS HIG: группированные карточки (Grouped List Cards) вместо урезанных таблиц.
   - Сенсорный минимум $\ge 44\times 44$px.
   - Natural Thumb Zone: компактные фильтры смены, чипы статусов «25 лотков», «Очистка: Норма».
   - 0px паразитного горизонтального скролла.

4. **Mobile Dark (390×844)**: `mobile_dark_sanpin_sterilization_390x844.png`
   - Тёмный режим на мобильном устройстве (390×844).
   - Читаемость кодов партий и регламентных параметров при выключенном освещении кабинета.

5. **Модальное окно пакетного подтверждения стерильности лотков**: `pc_light_batch_scanner_modal.png`
   - Замена поштучного сканирования крафт-пакетов на быстрое подтверждение партии.
   - По умолчанию стерильно согласно СанПиН 3.3686-21 при соблюдении параметров цикла (134°C, 2.15 бар, 5 мин) и норме химических индикаторов 4–5 классов.
   - Кнопка «Прикрепить партию лотков к приёму» (`.primary-button`).

6. **Модальное окно фиксации цикла автоклава**: `pc_light_autoclave_cycle_modal.png`
   - Запуск регламентного цикла стерилизации с автосписанием расходников со склада (Soft Negative Stock).
   - Валидация термодинамических параметров (134°C / 2.15 бар / 5 мин).
