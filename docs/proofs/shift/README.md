# Визуальные доказательства и спецификация модуля «Смена врача» (#shift)

## 1. Контекст очистки и клинической эргономики
В рамках инквизиторского аудита эргономики рабочего места врача (Red Team Inquisitor #2) выполнены ключевые очистки:
1. **Изоляция субаренды (Separation of Concerns):**
   - Из тулбара смены (`DoctorShiftControlBar.tsx`) полностью удалены переключатели субаренды кресла (`DoctorShiftFinancialModeToggle` сокращен до дефолтного процента/оклада, кнопка переключения удалена).
   - Из выпадающего меню смены (`DoctorShiftActionsDropdown.tsx`) удалены рудименты: `shift-action-handover` («Передать смену врачу») и `shift-action-rental-act` («Акт сверки субаренды»). Экономика субаренды кресла изолирована строго в модуле расчета зарплаты врачей (`components/payroll`).
2. **Мобильная сенсорная эргономика (Apple HIG):**
   - Устранено усечение текста на экранах 390px: метка `Касса (внесение/выплата)` в `MobileShiftBottomBar.tsx` заменена на лаконичное и чистое `Касса`.
   - Кнопки быстрого доступа `[ Касса ]` и `[ Расходники ]` имеют сенсорную высоту $\ge 44\text{px}$ и нулевое паразитное горизонтальное смещение.
3. **Закон анти-зависания смены (Anti-Hang Shift Law):**
   - Реализовано в `useShiftViewController.ts`: если врач не нажал кнопку закрытия смены, система предотвращает зависание смены на несколько суток.
   - Порог автозакрытия: 12 часов непрерывной активности (`DEFAULT_MAX_SHIFT_DURATION_HOURS = 12`) либо переход границы полуночи (`isPastMidnight`).
   - При срабатывании сбрасывается флаг `dente_doctor_shift_active`, очищается ключ таймера `dente_doctor_shift_start_time`, пишется телеметрия `staffTelemetryService.logShiftClose` с флагом `autoClosedByTimeout: true` и отправляется запрос на автозакрытие в фискальный API `/api/fiscal/shift/close`.
