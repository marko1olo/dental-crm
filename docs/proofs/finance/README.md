# Доказательства работоспособности (Visual Proofs) — Финансы, Касса, Чеки и Зарплата врачей

## 1. Контекст и архитектурная цель (Why)
- **Мандат 8e (Автономия врача и персонала)**: Устранение бюрократических барьеров и блокировок кассы. Для пациентов-физлиц ИНН строго опционален (`isRequired: false`, `isValid: true`), кнопки «Принять оплату» и «Кассовый чек» никогда не блокируются.
- **Мандат 8n (Суверенитет масштаба: соло-врач и небольшая клиника)**: Быстрый чекаут (Fast Checkout) в 1 клик со сплит-оплатой (Карта, СБП QR, Наличные, Семейный депозит, Гарантия 0 ₽), расчет сдачи без калькулятора, отказоустойчивость при сбоях фискального накопителя без повторного списания с баланса.
- **Мандат 8x (Живой человеческий клинический язык без канцелярита)**: Очистка прод-интерфейса от сырых номеров приказов, форм и разработческого сленга («54-ФЗ» -> «Кассовый чек», «КНД 1151156» -> «Справка для вычета (13% НДФЛ)», «Т-51» -> «Расчётный лист врача», «Прейскурант 804н» -> «Прейскурант услуг», «ККТ» -> «Кассовая смена»).
- **Мандат 8ze & Apple HIG (Сенсорная эргономика $\ge 44\times 44\text{px}$)**: Крупные тач-таргеты, Natural Thumb Zone, плавающая нижняя панель действий.
