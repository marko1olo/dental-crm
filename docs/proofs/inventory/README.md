   - Списание в тихом режиме уходит в отрицательные значения с пассивным бейджем овердрафта в бэкофисе для своевременного формирования дозаказа поставщику.

   - Вторичное действие в 1 клик: `[ ⚡ Списать расходники смены ]` по фактически закрытым визитам.

4. **Живой клинический язык (Мандат 8x)**:
