## 1. ИСПОЛНИТЕЛЬНОЕ РЕЗЮМЕ: ПОЧЕМУ ВРАЧИ ЛЮБЯТ EZDENT-I И ЧЕМ ГРЕШИТ НАШ ВЕБ-UI

При прямом визуальном аудите 15 реальных скриншотов работающей программы EzDent-i вскрывается фундаментальная истина: **стоматологический рентгеновский софт — это не фотошоп и не веб-галерея в стиле соцсетей**. Это высокоплотный, клинически выверенный инструмент, заточенный под работу врача у кресла за считанные секунды в перчатках.

### Главные эргономические триумфы EzDent-i:
1. **Железная 5-этапная архитектура вкладок (0-Click Workflow):**  
   Вся программа разделена на 5 понятных функциональных стадий: `ПАЦИЕНТ` ➔ `СНИМОК` ➔ `ПРОСМОТР ИЗОБРАЖЕНИЯ` ➔ `КОНСУЛЬТАЦИЯ` ➔ `ОТЧЕТ`. Никаких модальных матрёшек, никакого блуждания по бесконечным меню.
2. **Нижняя лента снимков (Persistent Filmstrip) с живым зумом превью:**  
   Вкладки «Просмотр», «Консультация» и «Отчет» сохраняют сквозную нижнюю горизонтальную ленту снимков пациента. Врач не переключает экраны, чтобы сличить снимок за май 2024 и октябрь 2026. Ползунок зума превью (от мелких иконок до крупных карточек) встроен прямо в статус-бар.
3. **Тактильный матричный поиск в 2 клика (Zero Typing):**  
   Вместо того чтобы заставлять врача вбивать даты в календариках или выбирать модальности из длинных выпадающих списков, EzDent-i предлагает матрицу крупных кнопок: слева — 7 режимов аппаратов (`Панорама`, `Цефалостат`, `КТ`, `IO-сенсор`, `IO-камера`, `Другое`), справа — 7 интервалов времени (`Сегодня`, `Вчера`, `3 дня`, `Прошлая неделя`, `Прошлый месяц`, `Все даты`). Поиск сегодняшних прицельных снимков визиографа занимает ровно 2 секунды.
4. **Клинический полноэкранный HUD (Screen 24):**  
   При разворачивании снимка на весь экран исчезает весь сайдбар и панели инструментов. Остается чистое медицинское поле 100% площади экрана, калибровочная линейка `5 mm` справа и аккуратный полупрозрачный желто-золотой блок телеметрии в верхнем левом углу: `ФИО`, `№ карты`, `Возраст`, `Дата`, `Зуб/Режим: 14`.
5. **Встроенная библиотека консультаций по 8 стоматологическим дисциплинам (Screens 25, 26):**  
   EzDent-i превращает диагностику в инструмент продажи плана лечения: сплит-экран сопоставляет реальный снимок пациента и типовую клиническую схему/анимацию патологии из 8 предустановленных разделов.
6. **Интерактивный конструктор отчетов с дозиметрией по СанПиН (Screens 27, 28, 29):**  
   Врач свободно перетаскивает снимки на лист, меняет их размер с помощью 8 маркеров трансформации, а система автоматически генерирует под каждым снимком лучевую нагрузку в единицах произведения дозы на площадь: **`dGy*cm^2 [DAP]`**, напряжение трубки (`kVp`) и ток (`mA`).

3. **8 категорий библиотеки консультаций (Снимок 26):**
   EzDent-i содержит зашитый структурированный справочник патологий и методов лечения по 8 разделам:
   1. **`Conservative Dentistry`** (Терапевтическая стоматология: кариес, пульпит, периодонтит, обтурация каналов).
   2. **`Prosthodontics`** (Ортопедическая стоматология: вкладки, виниры, металлокерамические и циркониевые коронки, мостовидные протезы).
   3. **`Periodontics`** (Пародонтология: гингивит, пародонтит, резорбция костной ткани, кюретаж, шинирование).
   4. **`Implant Dentistry`** (Дентальная имплантация: одномоментная, двухэтапная, синус-лифтинг, костная пластика).
   5. **`Oral Surgery`** (Хирургия: сложное удаление, ретенированные и дистопированные зубы мудрости, цистэктомия).

### 4.2. Блок быстрых фильтров DSP: `VisiographDspQuickToggles.tsx`
- Интеграция в левый сайдбар вьюпорта:
  ```typescript
  interface DspTogglesState {
    sharpness: boolean;      // Unsharp mask 3x3 (kernel [-1, -1, -1; -1, 9, -1; -1, -1, -1])
    maxSharpness: boolean;   // High-boost filter (kernel [-1, -2, -1; -2, 13, -2; -1, -2, -1])
    invert: boolean;         // 255 - value (негатив)
    pseudoRelief: boolean;   // Emboss filter (рельеф/трещины)
  }
  ```
- Кнопка «Сбросить» возвращает яркость/контраст в 0% и снимает все фильтры мгновенно.

### 4.3. Автономная калибровочная линейка: `VisiographScaleLadder.tsx`
- Отображение по правому краю вьюпорта:
  * Вертикальная градуированная полоса высотой `5 mm` (рассчитывается по формуле `(5.0 / pixelPitchMm) * zoomFactor`).
  * Четкие деления через каждый 1 мм с крупной отсечкой на 5 мм.
  * Текст `5 mm` полужирным контрастным шрифтом с подложкой.

### 4.4. Полноэкранный медицинский HUD: `VisiographFullscreenHud.tsx`
- При нажатии клавиши `F` или клике на иконку максимизации:

  * В левом верхнем углу выводится полупрозрачный HUD на темной подложке:
    - ФИО пациента, номер карты, возраст (лет).
    - Дата съемки и тип датчика (`IO-сенсор Vatech EzSensor Soft`).
    - Номер исследуемого зуба по формуле FDI (например, `Зуб: 14`).
  * Кнопка выхода из полноэкранного режима `[ ✕ ]` в правом верхнем углу (Esc также поддерживается).

### 4.5. Генератор радиологического листа печати: `RadiologyReportStudioModal.tsx`
