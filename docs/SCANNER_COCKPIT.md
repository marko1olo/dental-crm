# Рабочее место оцифровки документов регистратуры (Document Scanner Cockpit)

> 📇 **Каноническая архитектура сканирования и оцифровки документов в DENTE CRM**  
> **Маршрут:** `#scanner` (`view: "scanner"`)  
> **Мандаты:** Мандат 8e (Автономия врача и администратора), Мандат 8am (Ровно 1 Primary CTA), Apple HIG (Touch Ergonomics $\ge 44\times 44\text{px}$).

---

## 1. Назначение и Архитектурная Цель
Рабочее место «Сканер» в DENTE предназначено для мгновенной оцифровки физических документов пациентов администратором или врачом без сторонних утилит:
- Захват с аппаратной UVC-вебкамеры или настольного документ-сканера (USB/UVC).
- Fallback: загрузка PDF или фото через Drag-and-Drop / системный проводник.
- Направляющие рамки с фиксированным соотношением сторон (Aspect Ratio Guide Frames) под официальные стандарты РФ.
- Клиентская обработка на HTML5 Canvas (Контраст, Ч/Б бинаризация Оцу, Grayscale, поворот на 90°).
- Мгновенный детерминированный OCR парсинг реквизитов (Паспорт РФ, СНИЛС с контрольной суммой, Полис ОМС 16 цифр) без галлюцинаций LLM и без фейковых симуляций задержек.
- Интеграция с картотекой: поиск существующего пациента с быстрым прикреплением скан-копии в `/api/patients/:id/attachments` ЛИБО регистрация нового пациента в 1 клик с предзаполненными из OCR полями.

## 2. Клинические Пресеты Документов РФ

| Пресет | Соотношение сторон | Регулярные выражения / Формат | Назначение |
| :--- | :---: | :--- | :--- |
| **Паспорт РФ** | 1.42 (Разворот 2–3 стр.) | `(\d{2}\s*\d{2})\s*(\d{6})`, Код: `(\d{3}-\d{3})` | Основной документ, удостоверяющий личность |
| **Полис ОМС** | 1.58 (Единый образец) | `(\d{16})` (16 цифр подряд) | Полис обязательного медстрахования |
| **Полис ДМС** | 1.58 | Произвольный номер договора ДМС | Добровольное страхование |
| **СНИЛС** | 1.55 (Зеленое свидетельство) | `(\d{3}-\d{3}-\d{3}\s*\d{2})`, валидация контрольной суммы | Страховой номер индивидуального лицевого счёта |
| **Направление** | 1.414 (Вертикальный A4) | Направление на госпитализацию/обследование | Направление на лечение / консультацию |
| **Документ** | Свободное | Произвольный документ | Справки, выписки, чеки, гарантийные талоны |

## 4. Гарантии Эргономики и Доказательства

1. **Маршрутизация без конфликтов с боковым меню CRM:**
   - При клике по разделу «Стерилизация и автоклавы» (`#scanner`) по умолчанию открывается полноценный **Журнал стерилизации и санитарного режима** (`SanpinRegisters`: автоклавирование, предстерилизационная очистка, контроль индикаторов, крафт-пакеты).
   - Веб-камера сканера не стартует вхолостую, исключая ошибку `Permission denied`.
   - Сканер документов доступен в 1 клик через переключатель `[ Журналы СанПиН | Сканер документов ]`.
2. **Ликвидация советских приказов и канцелярита (Мандат 8x, 8ap):**
   - Устранен бюрократический атавизм «Форма 057/у» -> заменен на чистый семантический доменный пресет «Направление» (`referral_clinical`, «Направление на лечение / консультацию»).
3. **Ровно 1 Primary CTA (Мандат 8am):**
   - В режиме «Прикрепить к карте»: кнопка `[Прикрепить к карте пациента]`.
   - В режиме «Новый пациент»: кнопка `[Создать пациента и прикрепить скан]`.
   - Никаких конкурирующих акцентных кнопок в одном поле зрения.
4. **Автономия без блокировок (Мандат 8e):**
   - Кнопки съемки, сохранения и прикрепления никогда не имеют атрибута `disabled`. При нехватке данных пользователю выводится деликатная плашка с подсказкой.
5. **Apple HIG & Сенсорный минимум:**
   - Высота интерактивных элементов на мобильных экранах $\ge 44\times 44\text{px}$.
   - Скроллируемая лента чипов пресетов без горизонтального дрифта родительского окна (`overflow-x: clip; max-width: 100vw;`).
