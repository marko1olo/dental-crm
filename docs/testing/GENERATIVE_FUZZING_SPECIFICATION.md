# 🧬 DENTE CRM — Спецификация Медицинского Генеративного Фаззинга и Стохастического Хаоса (Medical Domain Generative Fuzzing & Stochastic Chaos Specification)

> **Статус документа:** Активный / Single Source of Truth (SSOT)  
> **Мандаты:** Мандат 8a (T.A.R.S. 100% честность), Мандат 8b (Математика денег и точные копейки), Мандат 8e (Врачебная автономия и 100% скидки), Мандат 8n (Суверенитет масштаба и мягкий овердрафт), Мандат 8t (Защита хоста и время выполнения <3000ms), Мандат 8ar (Анатомическая сетка Wheeler 2.5D), Мандат 8as (Матрица Блэка I–VI).  
> **Автор:** Главный Инженер Медицинского Фаззинга, Генеративного Тестирования и Стохастического Хаоса (L2 Domain Lead).

---

## 1. МАНИФЕСТ И КЛИНИЧЕСКОЕ ОБОСНОВАНИЕ ФАЗЗИНГА В DENTE CRM

Реальная частная стоматологическая клиника РФ сталкивается с колоссальной энтропией данных:
1. **Прайс-листы поставщиков и старых баз на 10 000+ строк**: битые кодировки, советские форматы цен («1500-00», «от 3000 руб.»), отсутствующие или смешанные латиницей/кириллицей коды Номенклатуры 804н, неразрывные пробелы (`\u00A0`), эмодзи и кавычки.
2. **Стоматологические формулы зубов FDI (ISO 3950)**: постоянный прикус (11..48), молочный прикус (51..85), смешанный прикус у детей 6–12 лет со строгими биологическими парами смены зубов, частичная и полная адентия (классификации Кеннеди I–IV), сверхкомплектные зубы (91..98) и экстренный свободный ввод врача со срезанными знаками и опечатками.
3. **Финансовые расчеты и сплит-чеки по 54-ФЗ**: суммы от 1 копейки до 100 000 000 рублей, произвольное количество участников сплита (2..10 кошельков), скидки врача от 0% до 100% (Мандат 8e) со строгим сохранением баланса до последней неделимой копейки без IEEE-754 `float` погрешностей.
4. **Санитарно-эпидемиологические журналы СанПиН 3.3686-21**: расчет сроков годности стерильности упаковок с переходом через границы високосных годов (29 февраля), границы столетий (1900, 2000, 2100) и защитой от падений рантайма по `RangeError: Invalid time value`.

Обычные статические юнит-тесты проверяют 2–3 идеальных случая. Архитектура генеративного фаззинга DENTE прогоняет десятки тысяч стохастических комбинаций за доли секунды и математически доказывает несокрушимость ядра CRM.

## 2. АРХИТЕКТУРА И ДЕТЕРМИНИРОВАННЫЙ PRNG (FASTPRNG)

### Модуль: `packages/shared/src/fuzzing/generators/medicalFuzzerGenerators.ts`

Фаззинг построен на детерминированном 32-битном псевдослучайном генераторе **Mulberry32**.  
**Преимущества:**
- **Абсолютная воспроизводимость (Zero Flaky Tests):** каждый тестовый запуск инициализируется фиксированным или залогированным числовым `seed` (по умолчанию `20261106`, `424242`, `888123`). Любое гипотетическое падение повторяется одной строкой кода.
- **Сверхвысокая скорость (Nanosecond Latency):** битовые операции `Math.imul` без накладных расходов V8 позволяют выполнять 10 000 итераций фаззинга за **20–250 миллисекунд** (в 10 раз быстрее лимита Мандата 8t).

```ts
export class FastPrng {
    next(): number;                           // Равномерное [0, 1)
    nextInt(min: number, max: number): number; // Целое число [min, max]
    nextBigInt(min: bigint, max: bigint): bigint; // Целое BigInt [min, max]
    choice<T>(items: readonly T[]): T;        // Случайный выбор
    sample<T>(items: readonly T[], count: number): T[]; // Выборка N элементов
    shuffle<T>(items: T[]): T[];              // Перемешивание Фишера-Йетса
    boolean(prob?: number): boolean;          // Бернуллиевское испытание
    string(length: number, charset?: string): string; // Генератор случайных строк
}
```

## 3. СТОХАСТИЧЕСКИЕ ГЕНЕРАТОРЫ И ДОМЕННЫЕ ИНВАРИАНТЫ

### 3.1. Генератор зубных формул (`FdiToothFuzzer`)
1. **Постоянный прикус (32 зуба):** квадранты 1..4 (11..18, 21..28, 31..38, 41..48).
2. **Молочный прикус (20 зубов):** квадранты 5..8 (51..55, 61..65, 71..75, 81..85).
3. **Сменный прикус (Mixed Dentition):** дети 6–12 лет. Моляры 16, 26, 36, 46 присутствуют всегда. Для остальных позиций соблюдается биологическая преемственность (зуб 51 замещается на 11, 52 на 12 и т.д.). Исключено одновременное нахождение в дуге молочного зуба и его постоянного преемника.
4. **Адентия по Кеннеди (Kennedy Classes I–IV):**
   - Класс I: двусторонние концевые дефекты (отсутствуют 48, 47, 46 и 36, 37, 38).
   - Класс II: односторонний концевой дефект (отсутствуют 48, 47, 46).
   - Класс III: односторонний включенный боковой дефект (отсутствуют 46, 45).
   - Класс IV: одиночный включенный дефект фронтальной группы, переходящий через среднюю линию (отсутствуют 41, 31, 42, 32).
5. **Генератор грязных строк сокращений (Shorthand Token Fuzzing):**
   - Замещения гомоглифов кириллицы/латиницы: `с`/`c`, `о`/`o`/`0`, `р`/`p`, `к`/`k`, `а`/`a`.
   - Пробельные бомбы до 100 пробелов и символов табуляции.
   - Спецсимволы, эмодзи, пунктуационные разделители (`/`, `\`, ` - `, `:`, `=`).
   - Сверхкомплектные зубы (91..98, 19, 29, 39, 49) и невалидные номера (99, 0, -1, 100, 999).
   - **Инвариант 1:** 0 необработанных исключений и крашей рантайма.
   - **Инвариант 2:** 100% распознанных зубов строго принадлежат каноническому множеству `ALL_FDI_TEETH`.

### 3.2. Генератор финансовой математики (`BillingMathFuzzer`)
1. **Диапазон сумм:** от 1 копейки (`1n`) до 100 000 000 рублей (`10_000_000_000n` копеек).
2. **Сплит-платежи:** произвольное число плательщиков (2..10).
3. **Врачебная скидка (Мандат 8e):** от 0.00% до 100.00% (базисные пункты 0..10000). 100% скидка дает ровно 0 копеек к оплате без деления на ноль.
4. **Инвариант Гамильтона-Хэра (Largest Remainder Method):**
   - $\sum \text{splits} \equiv \text{payableKopecks}$ (ноль копеечных погрешностей).
   - Разница между максимальной и минимальной долями участников не превышает **1 копейку** при равном распределении.
   - При делении 1 копейки на 3 плательщиков: доли строго `[1, 0, 0]`, сумма $\equiv 1$.
   - При делении 2 копеек на 3 плательщиков: доли строго `[1, 1, 0]`, сумма $\equiv 2$.
5. **Мультитендерные чеки 54-ФЗ:** распределение наличности (1031), безналичных (1081), авансов/депозитов (1215) и кредита (1216) со строгим нулевым расхождением `discrepancyKopecks === 0`.

### 3.3. Генератор грязных прайс-листов (`PricelistFuzzer`)
1. **Размер датасетов:** от 50 до 10 000 строк.
2. **Форматы поставщиков (Vendor Signatures):** IDENT, DentalPRO, iStom, 1C:Медицина, Generic Tabular.
3. **Хаос клинических данных:**
   - Экстремальные длины наименований: пустые строки, 1 символ, 500..2000 символов.
   - Советская бухгалтерская нотация: `1500-00`, `2 500,50 руб.`, `от 3000 ₽`.
   - Бесплатные/гарантийные позиции: `0`, `0 руб`, `0.00`, `бесплатно`, `по гарантии` $\to$ распознаются с `priceRub: 0`, `isWarrantyOrFree: true`.
   - Договорные цены: `по договоренности`, `по факту` $\to$ фиксируются ошибкой без краша.
   - Отрицательные цены (`-1500`) и суммы $>10\,000\,000$ рублей $\to$ бракуются валидатором.
   - Коды Номенклатуры 804н с кириллическими литерами (`а16.07.002`).

### 3.4. Генератор дат СанПиН и стерильности (`SanpinDatesFuzzer`)
1. **Високосные года:** 29 февраля 2024, 2028, 2032 и столетний високосный 2000 год.
2. **Невисокосные столетия:** 1900 и 2100 года (не делятся на 400).
3. **Переходы через рубежи веков:** 1999-12-31 $\to$ 2000-01-01.
4. **Отрицательные интервалы:** дата упаковки позже контрольной даты (вскрытие до упаковки).
5. **Защита от RangeError (`safeCalculateExpiry`):** невалидные строковые даты (`2024-13-45`, `yesterday`, пустые строки) перехватываются без выброса `RangeError: Invalid time value` и возвращают структурированный статус ошибки.

## 5. ЭКСПОРТЫ И ИНТЕГРАЦИЯ В МОНОРЕПОЗИТОРИИ

Архитектура фаззинга экспортируется через канонический фасад `@dental/shared`:
```ts
import {
    FastPrng,
    FdiToothFuzzer,
    BillingMathFuzzer,
    PricelistFuzzer,
    SanpinDatesFuzzer,
} from "@dental/shared";
```

Все компоненты проверены `npm run check:encoding` (UTF-8 без BOM) и готовы для использования в тестах надежности и E2E сьютах CRM DENTE.
