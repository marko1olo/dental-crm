## 2. СОСТАВ АВТОМАТИЗИРОВАННЫХ ТЕСТОВ (`clinicalEmrLifecycle.test.ts`)

### Сьют 1: Валидация зубных номеров FDI и связывание с МКБ-10
1. `1.1. Постоянный прикус`: валидация зубоспецифичного диагноза K02.0 (Кариес эмали) с постоянным зубом 16 по системе FDI (ISO 3950).
2. `1.2. Молочный (детский) прикус`: валидация K02.0 с молочным зубом 54 (диапазон квадрантов 5–8, зубы 51–85).
3. `1.3. Пульпит K04.0`: строгий контроль обязательности зуба FDI (`ToothRequired`) при отсутствии номера и успешное связывание при валидном номере.
4. `1.4. Хронический пародонтит K05.3`: опциональность зуба (генерализованная форма без номера зуба и локализованная группа зубов 31, 32).
5. `1.5. Отклонение невалидных зубов`: пресечение номеров 99, 0, 19, 49 с возвратом клинической ошибки `ToothInvalid`.
6. `1.6. Отклонение не-стоматологических кодов`: отсечение чуждых кодов (J06.9 ОРЗ, I10 Гипертония) с ошибкой `Icd10Invalid`.
7. `1.7. Нормализация ввода`: автоматическая замена кириллической «К»/«к» на латинскую `K`, удаление лишних пробелов, расстановка точек («к021» $\to$ `K02.1`).

### Сьют 2: Соматическая безопасность и фолбек при отсутствии патологий
8. `2.1. Безопасность на пустых данных`: передача `null`, `undefined` или пустой строки `""` возвращает физиологическую норму (`isHealthyNorm: true`) и канонический текст «Соматически здоров. Аллергоанамнез не отягощен...» без выброса `TypeError`.
9. `2.2. Аллергия на анестетики`: выявление аллергии на Лидокаин и Новокаин с установкой флага `hasCriticalStop` и рекомендацией безадреналинового Мепивакаина 3%.
10. `2.3. Кардиоваскулярный риск`: выявление инфаркта миокарда (< 6 мес) с формированием категорического запрета на адреналин 1:100 000.

### Сьют 3: Автосохранение черновика визита с частичными данными (Мандат 8e)
11. `3.1. Черновик только с жалобами`: врач набрал только жалобу («Ноющая боль в 46»), остальные поля пусты — сервер возвращает 200 OK без 500 Internal Error.
12. `3.2. Черновик только со статусом зуба и диагнозом`: сохранение частичных объективных данных без блокировки.
13. `3.3. Реактивное восстановление (GET)`: проверка отсутствия амнезии данных — GET возвращает все сохраненные поля черновика в точности 1:1.

### Сьют 4: Церемония подписания ПЭП, SHA-256 хеш и версионный аудит
14. `4.1. Подписание дневника врачом`: фиксация математически детерминированного SHA-256 хеша протокола (`computeDiaryHash`), блокировка записи (`isLocked: true`, `lockedAt`), запись в `clinical_audit_logs`.
15. `4.2. Защита от подделки (Tamper-Proofing)`: попытка прямой модификации заблокированного дневника отклоняется с кодом 403 `DiaryLocked`.
16. `4.3. Ревизия («Исправленному верить»)`: внесение клинического уточнения через маршрут ревизии сохраняет предшествующую редакцию в `visit_diary_revisions`, инкрементирует `revisionCount`, обновляет хеш и снимает криптоподпись для повторного заверения врачом.

### Сьют 5: Структура печатного бланка A4 и соответствие Мандату 8x
17. `5.1. Водяной знак черновика`: незакрытый приём выводит полупрозрачный диагональный штамп `ЧЕРНОВИК`.
18. `5.2. Штамп подписанного документа`: закрытый приём выводит официальный штамп `ПОДПИСАНО ВРАЧОМ`.
19. `5.3. Целостность медицинской структуры`: бланк содержит паспортную часть (ФИО, дата рождения, паспорт), анамнез, статус, диагноз МКБ-10, протокол лечения и подпись врача.
20. `5.4. Мандат 8x (Чистый клинический язык)`: заголовок `<title>` строго содержит «Медицинская карта приёма № ...», отсутствуют архаичные советские канцеляризмы («043/у», «804н»).

## 4. КЛИНИЧЕСКИЕ ИНВАРИАНТЫ ДЛЯ РАЗРАБОТЧИКОВ

1. **Никаких 500 ошибок на частичных данных (Мандат 8e):** Врач может сохранить карточку, заполнив всего одно поле (например, только жалобу или только зуб).
2. **Безопасная норма по умолчанию:** Пустой анамнез = соматически здоров, без аллергий. Система не навязывает 50 чекбоксов.
3. **Неизменяемость после подписи:** Прямой PUT/POST в подписанный дневник заблокирован (403 `DiaryLocked`). Правки допустимы исключительно через `POST /api/diaries/:id/revise` с фиксацией клинической причины и сохранением истории в `visit_diary_revisions`.
4. **Чистый русский язык (Мандат 8x):** В UI и печатных формах строго используются живые профессиональные термины: «Медицинская карта приёма», «Дневник приёма», «Прейскурант».
