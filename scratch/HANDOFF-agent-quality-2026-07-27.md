**Без визуального перегруза.** Чисто, дышаще. Глубину прятать под «показать

**Модульность.** clinicMode / флаги / пресеты, а не хардкод. Мелкий кабинет не
должен видеть лишнего. Анти-монолиты: большие файлы пилить на доменные
компоненты, но декомпозиция должна быть настоящей (компонент импортирован и

**Приоритеты усилий.** Больше реальной работы — меньше возни с документацией и

## 4. GIT

- Ветка `main`. **Два remote**: `origin` (GitHub) и `gitlab`. Пушить в оба:
  `git push origin main && git push gitlab main`.
- `git push --all` **не использовать** — в репозитории десятки старых веток,
  часть отстала, пуш падает целиком.
- Вывод пуша **редактировать**: `| sed -E 's#https://[^@]*@#https://***@#g'`.
  В URL remote зашиты живые токены. Заказчик сказал: «похуй на токены если они не
  текут в инет» — но вывод всё равно чистить.
- `scratch/` **не в gitignore** и частично отслеживается. `git add scratch/`
  целиком — нельзя.
- **Коммитить только своими путями.** Второй агент держит в общем индексе свои
  застейдженные файлы. `git commit` без pathspec заберёт и их. На этом отрезке
  пронесло (проверено `git show --stat` по каждому коммиту), но впредь
  безопаснее: `git commit -- путь1 путь2` или проверять `git diff --cached --name-only`
  перед коммитом.
- Гейт `THE IRON GATE` на pre-commit: gitleaks (проходит), Biome (не установлен,
  пропускается).

  коде. Всегда делать контроль отката: откатить правку, убедиться, что проверка
  падает, вернуть.
- **Ожидание может быть неверным, а код — целым.** Дважды сочинял неверное
  ожидание: «на формуле Б не должно быть диагнозов» (пять из них её собственные) и
  «владелец получит 200 на /api/max/settings» (там законный 404 «бот не
  настроен»). Прежде чем объявлять дефект — проверить фактическое состояние
  данных запросом к API или базе.
- **Скриншот может быть не того.** Всегда печатать, что на кадре, и убеждаться,
  что это не логин и не пустая страница.
- **Инструмент Edit ломается на не-ASCII.** При правке строк с кириллицей и
  типографикой `old_string` часто не совпадает. Помогает: короткий якорь без
  ведущих пробелов, либо полный `Write` файла после `Read`. Один раз Write записал
  комментарий escape-последовательностями и испортил файл — проверять результат
  через `Read` или `grep`.
- **`git commit` без pathspec** заберёт чужое из общего индекса.
- **Сервер разработки флапает.** Живые проверки — только с повторами.
- **Не бывает «пустой» heredoc с python** — команда зависает на 2 минуты. Не
  использовать.
