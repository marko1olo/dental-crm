## 3a. ГЛАВНЫЙ ВЫВОД ОТРЕЗКА

**Снимок экрана не показывает, что раздел упал.** Граница ошибок React рисует
вежливое «Раздел временно не открылся. Уже введенные данные не менялись», и это
выглядит как обычное пустое состояние. Четыре раздела из двадцати двух не
открывались вовсе, и по снимкам это было незаметно.

Поэтому перед разбором дизайна прогоняйте `scratch/audit-route-crashes.mjs`: он
обходит все разделы и вкладки, читает консоль браузера и отделяет настоящие
падения от пустоты. Каждый раздел смотрится с перезагрузки — граница ошибок не
сбрасывается при переключении вкладки, и без перезагрузки одна упавшая вкладка
показывает восемь поломок вместо одной.

Второй вывод: **декомпозиция здесь ломает приложение молча.** Вкладки вынесены
в отдельные компоненты копированием, а пропсы им прокинули частично. Три
инструмента поиска этого класса: `audit-settings-props.mjs` (что читают против
того, что передают), `probe-settings-locals.mjs` (локальные значения, которых
нет в источниках), `probe-helper-labels.mjs` (константы модулей, которые ждут в
пропсах).

## 5. ЛОВУШКИ, ДОБАВЛЕННЫЕ К ЧАСТИ 1

- **`\b` в JS не работает с кириллицей.** `\bприема\b` не совпадает никогда:
  граница слова определена по ASCII. Дважды написал проверку, которая падала на
  целом коде.
- **`toLocaleString("ru-RU")` разделяет разряды неразрывным пробелом** (U+00A0,
  в новых ICU — U+202F). Сравнение с обычным пробелом в тесте падает на верном
  выводе.
- **`POST /api/appointments` отвечает целым дашбордом, а не созданной
  записью.** `body.id` там нет. Уборка по идентификатору из ответа молча не
  удаляла ничего, и следующий прогон получал 409 «время занято». Убирать по
  метке в поле `reason` и печатать, сколько строк удалено.
- **Поиск по всему тексту экрана даёт ложные совпадения.** «Проверить снимок»
  нашлось в карточке пациента как часть «Проверить снимок перед переносом в
  ЭМК». Проверять принадлежность строки конкретному блоку через
  `querySelector(...).textContent`.
- **Заголовки HTTP — ByteString.** Кириллица в значении заголовка роняет fetch:
  «Cannot convert argument to a ByteString».
- **`git stash push` с несуществующим путём завершается ошибкой и НЕ создаёт
  стеш**, а следующий `git stash pop` тянет чужой стеш из общего дерева. В
  списке лежат стеши других сессий. Не пользоваться stash в общем дереве.
- **Рабочий каталог bash сбрасывается на `c:\hades`** посреди сессии. Признак:
  `npm error No workspaces found`. Возвращаться `cd /c/Clinic_MVP/dental-crm`.
- **python heredoc зависает на две минуты** — предупреждение из части 1
  подтверждено на своём опыте.
- **`@dental/shared` резолвится в `dist`, не в `src`.** Правка схемы в `src`
  без `npm run build -w @dental/shared` не действует, и API продолжает
  работать по старому контракту.
