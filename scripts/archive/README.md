# Scripts Archive (Исторический архив скриптов)

Данная директория содержит архивированные одноразовые и исследовательские скрипты прошлых волн разработки DENTE CRM.
Скрипты вынесены из корня `scripts/` для поддержания порядка, устранения визуального и поискового шума и снижения когнитивной нагрузки.

## Структура архива

1. **`cbct-research/`**
   - Алгоритмические исследования, калиперы, расчеты сплайнов зубной дуги, детекция эмали, центроидов корней и морфологические тесты КТ/CBCT (исследования Барабаш, Захаров, Буляков).
   - Сохранены как ценный математический и алгоритмический референс.

2. **`waves/`**
   - Исторические смоук-тесты краевых клинических сценариев прошлых волн (`test-edge-cases-wave6.mjs` .. `wave15.mjs`).
   - Удалены из активной секции `scripts` в `package.json`, сохранены для верификации ретроспективы.

3. **`inquisitions/`**
   - Одноразовые скриншотные и визуальные инквизиции прошлых волн (`capture-wave43-proofs.mjs`, `themes_10_pc_inquisition_runner.cjs`, `take_live_audit_wave125.cjs`, `wave8-multimodal-visual-audit.mjs` и др.).

4. **`proof-generators/`**
   - Вспомогательные Python-скрипты генерации коллажей и аудита печатных форм (`generate_tooth46_collages.py`, `verify_legal_block_final.py`).
