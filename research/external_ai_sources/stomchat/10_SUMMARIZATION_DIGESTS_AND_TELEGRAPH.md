## 1. АРХИТЕКТУРА РЕГУЛЯРНЫХ ДАЙДЖЕСТОВ

В активном чате за сутки может накапливаться от 500 до 2000 сообщений. Практикующему врачу некогда читать бесконечную ленту. Дайджест-система StomChat автоматически трансформирует поток переписки в структурированные клинические статьи.

```
                      Суточный поток сообщений (messages)
                                       │
                                       ▼
        ┌────────────────────────────────────────────────────────┐
        │ 1. ФИЛЬТРАЦИЯ И СЕМАНТИЧЕСКИЙ ОТБОР                    │
        │    - filter_useful_messages(): отсечение флуда         │
        │    - Выделение веток с реальными клиническими кейсами  │
        └──────────────────────────────┬─────────────────────────┘
                                       │
                                       ▼
        ┌────────────────────────────────────────────────────────┐
        │ 2. СТРУКТУРИРОВАНИЕ КЛИНИЧЕСКИХ БЛОКОВ                 │
        │    - "Разбор под микроскопом" (главный кейс суток)     │
        │    - "Доказательная база EBM" (стандарты и статьи)     │
        │    - "Клинические грабли" (ошибки и осложнения)        │
        │    - "Жемчужины чата" (практические лайфхаки)          │
        └──────────────────────────────┬─────────────────────────┘
                                       │
                    ┌──────────────────┴──────────────────┐
                    ▼                                     ▼
        ┌───────────────────────┐             ┌───────────────────────┐
        │ ЕЖЕДНЕВНЫЙ ДАЙДЖЕСТ   │             │ ЕЖЕНЕДЕЛЬНЫЙ ВЫПУСК   │
        │ - Публикация в        │             │ - Масштабный лонгрид  │
        │   Telegraph API       │             │ - Верстка PDF-журнала │
        │ - Пост в чат с ссылкой│             │   (digest_pdf.py)     │
        │ - Безопасный закреп   │             │ - Отправка документа  │
        └───────────────────────┘             └───────────────────────┘
```

## 2. ИНТЕГРАЦИЯ С TELEGRAPH API (`_create_telegraph_page_resilient`)

- Создание независимых иллюстрированных статей через `telegraph.Telegraph`.
- **Встраивание медиа (`embed_media_into_summary_html`):** Если в ходе обсуждения клинического случая врачи публиковали снимки КЛКТ или фотографии этапов лечения, скрипт находит оригинальные файлы из `uploaded_media/` и вставляет их в тело статьи Telegraph.
- **Отказоустойчивость:** При ошибках сети или таймаутах Telegraph API предусмотрен трехкратный экспоненциальный бэкофф с сохранением резервной HTML-версии на локальный диск.

## 3. ГЕНЕРАТОР PDF-ЖУРНАЛА ВЫСОКОГО РАЗРЕШЕНИЯ (`digest_pdf.py`)

По воскресеньям система формирует полноценный клинический журнал за прошедшую неделю:
- Использование HTML5-шаблона со стилизацией под премиальные медицинские периодические издания (шрифты Georgia / Inter, многоколоночная верстка, сноски, подписи к рентгенограммам).
- Автоматический рендеринг через движок WeasyPrint в высококачественный PDF (векторный текст, сохранение ссылок, нумерация страниц).
- Готовый PDF-файл выкладывается прямо в группу Telegram в виде документа с интерактивной карточкой описания выпуска.
