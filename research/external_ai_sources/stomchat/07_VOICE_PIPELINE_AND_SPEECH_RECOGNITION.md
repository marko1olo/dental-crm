## 1. АРХИТЕКТУРА ОБРАБОТКИ ГОЛОСОВЫХ СООБЩЕНИЙ

Врачу у кресла в перчатках неудобно набирать длинные сообщения на клавиатуре. Поэтому значительная часть сложных клинических кейсов отправляется в виде голосовых сообщений.

```
                      Голосовое сообщение врачей (Telegram .OGG Opus)
                                             │
                                             ▼
        ┌────────────────────────────────────────────────────────────────────────┐
        │ 1. ЗАГРУЗКА И ВАЛИДАЦИЯ ФАЙЛА                                          │
        │    - Загрузка аудиопотока через Telethon                               │
        │    - Ограничение по размеру (< 20 МБ) и длительности                   │
        └───────────────────────────────────┬────────────────────────────────────┘
                                            │
                                            ▼
        ┌────────────────────────────────────────────────────────────────────────┐
        │ 2. КОНВЕРТАЦИЯ В FFMPEG                                                │
        │    - convert_to_wav(): преобразование в 16 kHz Mono PCM WAV            │
        │    - is_audio_silent_or_empty(): детекция тишины и случайных кликов    │
        └───────────────────────────────────┬────────────────────────────────────┘
                                            │
                                            ▼
        ┌────────────────────────────────────────────────────────────────────────┐
        │ 3. РАСПОЗНАВАНИЕ РЕЧИ (Whisper / Gemini Multimodal)                    │
        │    - Прямое декодирование аудиодорожки в текстовый транскрипт          │
        └───────────────────────────────────┬────────────────────────────────────┘
                                            │
                                            ▼
        ┌────────────────────────────────────────────────────────────────────────┐
        │ 4. ФОНЕТИЧЕСКАЯ КОРРЕКЦИЯ ТЕРМИНОЛОГИИ (dental_vocab.py)               │
        │    - Исправление искаженных стоматологических терминов                 │
        │    - Восстановление англоязычных брендов и аббревиатур                 │
        └───────────────────────────────────┬────────────────────────────────────┘
                                            │
                                            ▼
        ┌────────────────────────────────────────────────────────────────────────┐
        │ 5. ПУБЛИКАЦИЯ И СОХРАНЕНИЕ В БАЗУ                                      │
        │    - _publish_voice_transcription(): публикация текстовой расшифровки  │

        └────────────────────────────────────────────────────────────────────────┘
```

## 2. СТОМАТОЛОГИЧЕСКИЙ СЛОВАРЬ И ФОНЕТИЧЕСКИЙ ПОСТПРОЦЕССИНГ

Обычные модели распознавания речи (включая Whisper и облачные API) обучены на бытовом корпусе языка и систематически искажают стоматологический сленг и специфические названия:

| Что слышит стандартная модель | Правильный стоматологический термин | Пояснение |
| :--- | :--- | :--- |
| *кофердам, кофер* | **коффердам** | Система латексной изоляции |
| *верти преп, вертикал* | **вертипреп (Vertiprep)** | Вертикальное препарирование без уступа |
| *борт, бопт* | **BOPT** | Biologically Oriented Preparation Technique |
| *реси прок, ресипрок* | **Reciproc** | Реципрокная эндодонтическая система |
| *било дентин, биодентин* | **Biodentine** | Биоактивный силикатный цемент |
| *эстилайт, астелайт* | **Estelite Asteria** | Светоотверждаемый реставрационный композит |
| *апекс локатор, апекс* | **апекслокатор** | Электронный прибор определения длины канала |
| *плагер, плагер* | **плаггер / спредер** | Инструменты вертикальной и латеральной конденсации |
| *эндо чак* | **эндочак** | Ультразвуковая насадка для эндодонтии |
| *гипохлорид* | **гипохлорит натрия (NaOCl)** | Основной ирригант корневых каналов |

В `blocking_tools.py` встроен специальный prompt-редактор, который сопоставляет сырой текст с матрицей `dental_vocab.py` и исправляет опечатки, сохраняя естественную речь врача.

## 3. ПУБЛИКАЦИЯ РАСШИФРОВКИ В ЧАТ (`_publish_voice_transcription`)

После успешного распознавания бот публикует в ветку обсуждения аккуратный транскрипт:
```html
🎤 <b>Голосовое сообщение врача:</b>
<i>«Коллеги, подскажите по 4.6 зубу. Вскрыл полость, устья облитерированы, MB2 в верхнем шестом не нахожу, на КЛКТ очаг 3 мм. Чем лучше мыть — теплым гипохлоритом или лимонкой?»</i>
```
**Преимущества:**
1. Коллеги, находящиеся на приеме или без наушников, могут мгновенно прочитать суть вопроса и ответить.
2. Текст сохраняется в базе `messages` и становится доступен поисковому движку RAG (`search_engine.py`) и недельному дайджесту.
