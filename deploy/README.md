# DENTE Dental CRM — 24/7 Cloud VPS Deployment Pack

Комплект автономного развертывания облачной инфраструктуры для частной стоматологической клиники.

Обеспечивает круглосуточную (24/7) работу онлайн-записи пациентов, Telegram WebApp, личного кабинета пациента (PWA) и портала зуботехнической лаборатории (ЗТЛ), даже если рабочий компьютер в клинике выключен ночью.

## ⚡ Быстрый старт за 3 шага

### Шаг 1. Подготовка сервера (VPS)
Купите любой стандартный VPS (Ubuntu 22.04 или 24.04 LTS).
- **Минимальные требования:** 1 vCPU, 1 GB RAM, 15 GB NVMe SSD.
- Направьте A-записи в DNS вашего домена на IP адрес VPS:
  * `@` -> `IP_ВАШЕГО_VPS`
  * `booking` -> `IP_ВАШЕГО_VPS`
  * `my` -> `IP_ВАШЕГО_VPS`
  * `lab` -> `IP_ВАШЕГО_VPS`
  * `relay` -> `IP_ВАШЕГО_VPS`

### Шаг 2. Копирование и запуск настройки
Подключитесь по SSH к VPS, скопируйте папку `deploy/` и запустите первичную настройку:
```bash
# Перейдите в папку deploy
cd deploy

# Запустите автонастройку (установка Docker, Docker Compose, UFW файрвол)
sudo ./setup-vps.sh
```

### Шаг 3. Конфигурация и запуск
```bash
# 1. Создайте файл конфигурации
cp .env.example .env

# 2. Отредактируйте переменные (укажите ваш домен и почту)
nano .env

# 3. Запустите стек одной командой
./deploy.sh
```

Caddy автоматически выпустит бесплатные SSL-сертификаты Let's Encrypt / ZeroSSL, поднимет HTTP/3 QUIC и запустит сервисы.

## 🌐 Доступные виртуальные хосты

После развертывания клиника получает 4 готовых боевых эндпоинта:

1. **`https://booking.yourdomain.com`**
   - Интерактивный онлайн-виджет записи пациентов.
   - Поддерживает мобильные экраны, сайт клиники (встраивание через `<iframe>`) и Telegram WebApp.
   - Если компьютер клиники выключен (ночью) — запись сохраняется в постоянную очередь Redis и подтверждается утром.

2. **`https://my.yourdomain.com`**
   - Личный кабинет пациента (Progressive Web App — PWA).
   - Вход по номеру телефона и SMS OTP.
   - История визитов, интерактивные планы лечения, электронные чеки 54-ФЗ и заказ справки на налоговый вычет 13% НДФЛ (ФНС КНД 1151156).
   - Поддерживает установку на экран смартфона («Добавить на экран Домой»).

3. **`https://lab.yourdomain.com`**
   - Портал зуботехнической лаборатории (ЗТЛ).
   - Просмотр нарядов врачей-ортопедов, зубных формул и сроков сдачи коронок/протезов.
   - Быстрое изменение статусов («Моделирование», «Фрезеровка», «Готово»).

4. **`wss://relay.yourdomain.com/ws/clinic`**
   - Защищенный WebSocket шлюз для связи локального сервера клиники с облаком.
   - Позволяет клинике за NAT работать без «белого» статического IP адреса.

## 🔌 Подключение локального сервера клиники

В файле `apps/api/.env` локального сервера клиники укажите:
```ini
CLOUD_RELAY_URL=wss://relay.yourdomain.com/ws/clinic
RELAY_SECRET=тот_же_секрет_что_и_в_deploy_env
```
При запуске сервер клиники автоматически установит исходящий туннель к вашему VPS.

## 🛠️ Команды управления

```bash
./deploy.sh status    # Проверка статуса контейнеров и портов
./deploy.sh logs      # Просмотр логов всех сервисов в реальном времени
./deploy.sh restart   # Перезапуск всех сервисов
./deploy.sh down      # Остановка всех сервисов
./deploy.sh test      # Тест внутренних эндпоинтов (Healthcheck)
./backup-s3.sh        # Ручной запуск резервного копирования очереди и сертификатов
```

## 🔒 Безопасность

- **Файрвол UFW:** Открыты только порты 22 (SSH), 80 (HTTP) и 443 (HTTPS/QUIC). Порты баз данных и внутренних микросервисов изолированы внутри Docker сети.
- **Заголовки безопасности:** Автоматические HSTS (`max-age=31536000`), CSP, `X-Content-Type-Options: nosniff`.
- **Защита от сбоев:** При перезагрузке VPS контейнеры поднимаются автоматически (`restart: always`).
